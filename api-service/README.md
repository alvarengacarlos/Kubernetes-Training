# API Service
## Description
Simple API to register phrases.

| Endpoints                  | Description       |
| -------------------------- | ----------------- |
| POST /phrases              | Register a phrase |
| GET /phrases/{phraseId}    | Get a phrase      |
| GET /phrases               | Get all phrases   |
| PUT /phrases/{phraseId}    | Update a phrase   |
| DELETE /phrases/{phraseId} | Delete a phrase   |
