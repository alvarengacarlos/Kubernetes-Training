# Kubernetes-Training
Simple examples to training Kubernetes.

## Create Resources
> Requirements:
> - Minikube
> - Bash
> - Kubectl CLI
> - Ingress Minikube Addon

Build images:
```bash
bash up.bash
```

> **Note:** You can destroy the images running: `bash down.bash`.
